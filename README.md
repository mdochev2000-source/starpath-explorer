# Starpath Explorer

Изследовател на звездни пътища. Задръж, за да се издигаш, пусни, за да падаш, и обикаляй около планетите по пътя към звездата.

Играй: отвори страницата на GitHub Pages в Chrome на телефона и избери „Инсталиране на приложението“.

## Приложение за Android (APK)

Последната версия за изтегляне е в **Releases** → `Starpath-Explorer.apk`. Играта е вградена в приложението и работи без интернет.
